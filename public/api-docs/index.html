Invoices API

Generate cross-chain USDC invoice links programmatically. One endpoint, action-based, no API key.

Endpoint POST https://www.invoices.wtf/api/relay

Create an invoice link

POST /api/relay

Generates an invoice exactly like the web form does — a random invoice ID, a deterministic deposit address derived from it, and a share URL that opens directly in the app.

FieldTypeNotes
actionstringrequiredmust be "createInvoiceUrl"
companyNamestringrequiredshown on the invoice
descriptionstringoptionaldefaults to empty
amountstringrequireddecimal USDC, e.g. "25" or "25.50" — not atomic units
destinationobjectrequiredsee below

destination — one of:

// EVM — Base, Arbitrum, or Polygon
{ "type": "evm", "chainId": 8453, "address": "0x..." }

// Solana — destination only, no chainId (Solana isn't EVM,
// so there's no equivalent small integer chain id to use)
{ "type": "solana", "address": "..." }

Supported EVM chainId values — the only chains covered by gasless relaying today:

  • 8453 · Base
  • 42161 · Arbitrum
  • 137 · Polygon

Request

curl -X POST https://www.invoices.wtf/api/relay \
  -H "Content-Type: application/json" \
  -d '{
    "action": "createInvoiceUrl",
    "companyName": "Loud Socks Studio",
    "description": "Podcast intro pack",
    "amount": "25",
    "destination": { "type": "evm", "chainId": 8453, "address": "0x1Cc1BD36202546E57B5337a8ba9BcC3Df815D3Cc" }
  }'

Response

{
  "invoiceId": "8d1c633a-8a33-44d3-aecb-8fb28fbf801f",
  "invoiceNumber": "INV-979707",
  "url": "https://www.invoices.wtf/#i=eyJ2Ijo2..."
}

Open url — that's the whole integration. The app takes it from there.

Errors

Every error returns a non-2xx status with a JSON body:

{ "error": "amount \"abc\" is not a valid decimal USDC value" }
